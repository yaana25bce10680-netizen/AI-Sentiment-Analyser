# AI Sentiment Analyser 

A simple, lightweight application to analyze text and detect emotional tone.

##  Introduction
For my **first-year engineering project**, I developed an **AI Sentiment Analyser**. The primary goal was to learn how to connect **AI logic** (using NLTK VADER) with a **web interface** (using Streamlit). The app allows users to type sentences and see instantly if the message is **Positive**, **Negative** or **Neutral**.

## Tech Stack
* **Language:** Python 3.x
* **AI Model:** NLTK VADER
* **Web Framework:** Streamlit
* **IDE:** Visual Studio Code

## Methodology and Approach
1.  **Setup:** Created a Python environment and installed libraries using `pip install`.
2.  **Logic:** Used the **VADER SentimentIntensityAnalyzer** to calculate emotion scores.
3.  **Frontend:** Built an interactive UI with a text box and an **"Analyze"** button.
4.  **Testing:** Ran the app on a **local server** to ensure everything worked correctly.

##  Challenges and Solutions
* **File Path Errors:** Fixed issues where the terminal couldn't find the code by using the `cd` command.
* **Installation Issues:** Resolved "Module Not Found" errors by correctly installing **Streamlit** and **NLTK**.

##  Limitations and Future Scope
* **Sarcasm:** The model may struggle with sarcastic sentences.
* **Languages:** Currently, the app only supports **English**.
* **Future:** I plan to add support for more languages and deploy it to the **cloud**.

##  Learning Skills
* **Coding:** Learned how to link backend AI to a frontend website.
* **Debugging:** Gained experience fixing real-world terminal and code errors.
* **Digital Tools:** Improved my ability to manage software files and folders.

##  Conclusion
This project successfully shows how **AI automation** can understand human emotions faster than manual review. It has given me a strong start in **Software Engineering** and **Artificial Intelligence**.
